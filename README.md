# ClipFlow

Telegram-бот, который скачивает видео по ссылке и присылает его прямо в чат.

Кидаешь ссылку на клип Twitch, VOD-стрим или видео с YouTube — бот сам
определяет платформу, подбирает подходящее качество и отправляет файл.
Если видео больше 2 ГБ (лимит Telegram на документ), бот режет его на
части через ffmpeg и присылает всё по очереди, не теряя ни куска.

## Поддерживаемые ссылки

- Twitch-клипы — `clips.twitch.tv/...`
- Twitch VOD — `twitch.tv/videos/...`
- YouTube — `youtube.com/watch?v=...`, `youtu.be/...`

## Как это работает

1. yt-dlp получает метаданные видео и пробует форматы по убыванию качества
   (для YouTube — 1080p → 720p → 480p → худшее, для Twitch — лучшее →
   худшее), пока скачивание не удастся.
2. Если итоговый файл больше 2 ГБ, `ffprobe` узнаёт длительность, и
   `ffmpeg -f segment` режет файл на части по ~1.9 ГБ без перекодирования.
3. Части отправляются в Telegram медиагруппами по 10 штук, с подписью,
   кто автор и какая это часть по счёту.
4. Пока идёт загрузка, бот обновляет статус-сообщение с прогрессом.

## Стек

- Python 3, [Pyrogram](https://docs.pyrogram.org/) (MTProto-клиент — нужен
  для загрузки файлов больше 50 МБ, с чем Bot API не справляется)
- [yt-dlp](https://github.com/yt-dlp/yt-dlp) для скачивания видео
- `ffmpeg` / `ffprobe` для разбиения больших файлов

## Запуск

```bash
cp .env.example .env
# заполнить BOT_TOKEN, API_ID, API_HASH (my.telegram.org)

pip install -r requirements.txt
python bot.py
```

Для разбиения больших файлов на хосте должен быть установлен `ffmpeg`.
